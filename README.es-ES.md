# HyprShaders ✨

Una colección seleccionada de shaders para Hyprshade que he recopilado (robado) con el tiempo.

Encuentra otros shaders geniales [aquí](https://www.shadertoy.com/)

## Instalación

```bash
git clone https://github.com/0x15BA88FF/hyprshaders.git
cp ./hyprshaders/shaders /path/to/shaders/dir/
```

## Uso

> [!NOTE]
> La mayoría de los shaders en este repositorio fueron probados para [Hyprshade](https://github.com/loqusion/hyprshade)
> pero podrían funcionar en otros renderizadores de shaders.

Con Hyprshade, puedes aplicar un shader con el siguiente comando:

```bash
hyprshade toggle /path/to/shader
```
